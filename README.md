# מבצעים ליד הבית

אפליקציה אישית: מעלים רשימת קניות, והיא בודקת מבצעים ברשתות המזון ברדיוס שבחרתם (ברירת מחדל 10 ק"מ) סביב המקום שבו אתם נמצאים, בארץ ובחו"ל.
כשנמצא מבצע חדש על מוצר מהרשימה נשלחת התראה עם המחיר ועם תאריך סיום המבצע.

## מאיפה מגיעים הנתונים
לפי חוק שקיפות המחירים, הרשתות מפרסמות קובצי סניפים (Stores), מחירים (PriceFull) ומבצעים (PromoFull).
השרת מוריד אותם, מאתר את הסניפים ברדיוס שלכם (בעזרת OpenStreetMap) ומתאים את המבצעים לרשימה.

רשתות נתמכות: שופרסל, רמי לוי, אושר עד, יוחננוף, טיב טעם, קשת טעמים, פרשמרקט, סאלח דבאח ודור אלון.
אפשר להוסיף רשתות בתיקייה `server/chains/`.

## בכל מקום בעולם
האפליקציה עוקבת אחרי המיקום שלך. בכל פעם שפותחים אותה, וכל 10 דקות כשהיא פתוחה, היא שולחת את המיקום לשרת.
אם זזת יותר מ-3 ק"מ, השרת מזהה את המדינה ובודק מבצעים מחדש.

| מדינה | מקור הנתונים |
|---|---|
| ישראל | קובצי שקיפות המחירים הרשמיים של הרשתות |
| אוסטריה, גרמניה | עלוני המבצעים לפי מיקוד, דרך marktguru (Billa, Spar, Hofer, Lidl, Penny, REWE, Edeka ועוד) |
| מדינות אחרות | עדיין אין מקור חינמי. האפליקציה תציג הודעה על כך, ואפשר להוסיף מקורות בתיקייה `server/providers/` |

- פריטי הרשימה מתורגמים אוטומטית לשפה המקומית (בשירות התרגום החינמי MyMemory). אפשר גם לכתוב שם מקומי אחרי קו: `חלב 3% | Milch`.
- המחירים מוצגים במטבע המקומי (€, A$ וכו').
- **מגבלה:** אפליקציית רשת יכולה לקבל מיקום רק כשהיא פתוחה. אם תנחתי בעיר חדשה ולא תפתחי את האפליקציה, השרת ימשיך לבדוק לפי המיקום האחרון שקיבל. מעקב ברקע כשהאפליקציה סגורה דורש גרסה מקורית לאנדרואיד ולאייפון (למשל עם Capacitor).

## הפעלה
```bash
npm install
npm run demo   # מצב הדגמה עם נתונים מדומים
npm start      # מצב אמיתי: http://localhost:3000
npm test
```

משתני סביבה:
| משתנה | תפקיד |
|---|---|
| `MOVE_KM` | מאיזה מרחק נחשב שזזת ונדרשת בדיקה חדשה (ברירת מחדל 3) |
| `APP_TOKEN` | סיסמה לאפליקציה. מומלץ מאוד כשהשרת פתוח לאינטרנט |
| `SCAN_EVERY_HOURS` | כל כמה שעות לסרוק (ברירת מחדל 3) |
| `MAX_STORES_PER_CHAIN` | כמה סניפים קרובים לבדוק בכל רשת (ברירת מחדל 3) |
| `VAPID_SUBJECT` | כתובת קשר להתראות, למשל `mailto:you@example.com` |
| `PORT`, `DATA_DIR` | פורט השרת ותיקיית הנתונים |

## מחשב, אנדרואיד ואייפון
זו אפליקציית רשת שאפשר להתקין (PWA), ולכן אותו קוד עובד בכל המכשירים:
- **מחשב**: פותחים את הכתובת ב-Chrome או ב-Edge. אפשר גם להתקין אותה מסרגל הכתובות.
- **אנדרואיד**: ב-Chrome פותחים את התפריט ⋮ ובוחרים „התקנת אפליקציה”, ואז מפעילים התראות בהגדרות.
- **אייפון**: ב-Safari לוחצים שיתוף ובוחרים „הוספה למסך הבית”, פותחים את האפליקציה מהאייקון ומפעילים התראות. נדרש iOS 16.4 ומעלה.

התראות ו-GPS בטלפון עובדים רק בכתובת **HTTPS**.

## איפה להריץ את השרת
מדריך מלא, צעד אחר צעד, להעלאה לשרת חינמי: [DEPLOY.md](DEPLOY.md)

השרת צריך לפעול כל הזמן כדי לסרוק ולשלוח התראות. אפשרויות:
- **מחשב בבית או Raspberry Pi**, עם Cloudflare Tunnel או Tailscale Funnel שנותנים כתובת HTTPS בחינם.
- **שרת VPS**. עדיף שרת בישראל, כי חלק מאתרי הרשתות בישראל חוסמים כתובות IP מחו"ל. השרת יכול להישאר בישראל גם כשאת בחו"ל: הבדיקה בחו"ל לא תלויה במיקום של השרת.

## הערות
- ההתאמה לפי שם עובדת לפי מילים: „חלב 3%” יתאים ל„חלב טרי 3% בקרטון”. כדי לקבל התאמה מדויקת אפשר לכתוב ברקוד.
- מבצעים שמוגבלים לחברי מועדון או לכרטיס אשראי מסומנים בתווית „מועדון”.
- על כל מבצע נשלחת התראה אחת בלבד. הרשימה המלאה תמיד מופיעה בלשונית „מבצעים”.
